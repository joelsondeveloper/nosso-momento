# 💕 Nosso Momento

Crie uma página personalizada para o seu amor com fotos, músicas, mensagens e uma linha do tempo dos momentos que vocês viveram juntos. Compartilhe com um link ou QR Code.

## Features

- 📸 Upload de fotos do casal
- 🎵 Integração com música (Spotify / YouTube)
- 💌 Mensagem personalizada
- ⏳ Contador de tempo juntos
- 🗓️ Linha do tempo de momentos
- 🔗 Link único + QR Code para compartilhar

## Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [Supabase](https://supabase.com/) (banco de dados + storage)
- [Tailwind CSS](https://tailwindcss.com/)

## Rodando localmente

\`\`\`bash
npm install
cp .env.example .env.local
# preencha as variáveis do Supabase no .env.local
npm run dev
\`\`\`
